# TasollerPlus

WindowsでTasoller Plusを扱うC#ライブラリです。機器の検出と接続、スライダー・AIRセンサー・FNボタンの入力取得、LEDの色指定ができます。

## 動作環境

対応機器はWinUSBモードの Tasoller Plus です。ライブラリは .NET Standard 2.1 をターゲットにしています。

## インストール

利用するC#プロジェクトのディレクトリで次のコマンドを実行します。

```powershell
dotnet add package TasollerPlus
```

使用例とAPIリファレンスは [GitHubのプロジェクトページ](https://github.com/Suiraaaa/tasoller-plus-dotnet) から参照できます。
