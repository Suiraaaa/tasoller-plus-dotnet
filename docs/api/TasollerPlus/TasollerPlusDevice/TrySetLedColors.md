# TasollerPlusDevice.TrySetLedColors method

スライダーと左右のAIRタワーのLED色を一括指定します。

```csharp
public bool TrySetLedColors(RgbColor[] slider, RgbColor[] leftAir, RgbColor[] rightAir)
```

| parameter | description |
| --- | --- |
| slider | スライダーの31枠に指定するRGB色です。 |
| leftAir | 左AIRタワーの3枠に指定するRGB色です。 |
| rightAir | 右AIRタワーの3枠に指定するRGB色です。 |

## Return Value

色指定を受け付けた場合は `true`、通信中でない場合は `false` です。

## Exceptions

| exception | condition |
| --- | --- |
| ArgumentException | いずれかの色配列が規定の要素数を満たしていません。 |

## Remarks

送信待ちの指定は最新の指定に置き換わります。最後に送信できた色は通信中に約1秒間隔で再送します。
